# Non-Functional Requirements

The following are the non-functional requirements for the MyWallet system.

| ID | Category | Non-Functional Requirements |
|---|---|---|
| NFR01 | Security | The system shall protect students' personal and financial information. |
| NFR02 | Usability | The system shall have a simple and user-friendly interface. |
| NFR03 | Performance | The system shall respond to user actions within an acceptable time. |
| NFR04 | Reliability | The system shall calculate income, expenses and remaining balance accurately. |
| NFR05 | Compatibility | The system shall be accessible through web browsers on smartphones and computers. |
| NFR06 | Availability | The system shall be accessible when students need to manage their finances.
