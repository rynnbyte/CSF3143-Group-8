# Functional Requirements

Based on the survey responses, the following are the functional requirements for the MyWallet system.

| ID | Functional Requirements |
|---|---|
| FR01 | The system shall allow students to register an account. |
| FR02 | The system shall allow students to log in to their account. |
| FR03 | The system shall allow students to record their income. |
| FR04 | The system shall allow students to edit and delete income records. |
| FR05 | The system shall allow students to record their daily expenses. |
| FR06 | The system shall allow students to categorize their expenses. |
| FR07 | The system shall allow students to edit and delete expense records. |
| FR08 | The system shall calculate the remaining balance based on income and expenses. |
| FR09 | The system shall allow students to set a monthly budget. |
| FR10 | The system shall display the amount of budget used. |
| FR11 | The system shall display a warning when students are close to or exceed their budget. |
| FR12 | The system shall generate monthly financial reports. |
| FR13 | The system shall allow students to view their transaction history. |
| FR14 | The system shall allow students to create savings goals. |
| FR15 | The system shall display the progress of savings goals.
