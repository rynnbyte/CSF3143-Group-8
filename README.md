# MyWallet: Student Financial Management System

## Project Description
MyWallet is a web-based financial management system
proposed to help UMT students manage their personal
finances.

## Main Features
- Income Management
- Expense Management
- Budget Management
- Financial Reports
- Savings Goals
- Budget Warnings

## Target Users
UMT Students
